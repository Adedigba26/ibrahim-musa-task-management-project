# TaskVault - CODAR Internship Assessment
By: Ibrahim Musa Opeyemi

Task Management App built with HTML, CSS, JavaScript.

Features:
- Add, Edit, Delete tasks
- Mark as Done
- Search and Filter (All/Pending/Completed)
- Counters: Total, Done, Pending
- LocalStorage save
- Validation message: kindly add task name here
- Responsive

How to Run:

Open index.html with Live Server

Files:
index.html, style.css, script.js, README.md
